# Sounds of Joy — POJ Original Songbook (2013–2026)

Canonical archive of **16 Easter Camp (CCM) original worship songs** written by the **Place of Joy (POJ)** Melbourne community (13 archived in [`songs/`](./songs), 3 missing from CCM22).

- **Web Songbook (12-Key & Nashville Transposer):** [soundsofjoy.vercel.app](https://soundsofjoy.vercel.app)
- **Full Song Directory Table (Credits, Keys, Audio & Sources):** [`DIRECTORY.md`](./DIRECTORY.md)
- **Bundled Audio Recordings (`audio/`):** [`audio/README.md`](./audio/README.md)
- **Repository & Technical Documentation:** [`DOCS.md`](./DOCS.md)
