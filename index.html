Markdown + YAML Songbook Repository

Deploy to GitHub & soundsofjoy.vercel.app

Every song lives in songs/<year>-<slug>.md with a structured YAML frontmatter header, alongside bundled original recordings in audio/.

Step 1: Push Unzipped Repo to GitHub

Create or update your sounds-of-joy repository on GitHub, then run inside the unzipped folder:

git init
git add .
git commit -m "Sounds of Joy: Markdown + YAML songbook, credits & audio"
git branch -M main
git remote add origin https://github.com/<YOUR_USER>/sounds-of-joy.git
git push -u origin main

Step 2: Import into Vercel

  1. Open vercel.com/new and select your sounds-of-joy GitHub repository.
  2. Set Project Name to soundsofjoy.
  3. vercel.json automatically runs node scripts/build-songbook.js whenever you edit or add any songs/*.md file on GitHub.
  4. Click Deploy — your site publishes at https://soundsofjoy.vercel.app.

Markdown + YAML Song Format (songs/*.md)

---
id: "rooted"

year: 2026
